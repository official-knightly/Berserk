# Berserk WebAssembly builds

This directory is generated by [build-wasm-api.yml](../.github/workflows/build-wasm-api.yml) from the Rust engine source in this repository.

- `browser/` contains the `--target web` JavaScript glue and `berserk_bg.wasm` for browser apps.
- `worker/` contains the `--target bundler` JavaScript glue and `berserk_bg.wasm` used by the Cloudflare HTTP API.

Do not edit generated JavaScript or WebAssembly by hand. Change the engine in `src/` and rebuild from source.

## Browser use

Serve `wasm/browser/` over HTTP(S), import `berserk.js` as an ES module, and initialize it with the path to `berserk_bg.wasm`. Run searches in a Web Worker to keep the UI responsive.

## HTTP API

The API Worker source is in `api/worker.mjs`. It imports the generated worker-target bindings and runs the real Rust engine compiled to WASM. See the repository README for API endpoints and request examples.

The hosted Worker requires a Workers plan that permits the configured CPU budget. A deployment is not considered verified until a real `POST /v1/bestmove` request returns a legal move.
